# GitHub Bootstrap Policy

GitHub repository and Actions links do not exist before P0 and are not documentation gaps.

Creation: verified local repo → create GitHub repository → record URL → push main → CODEOWNERS/PR template → governance/build/test/security workflows → Rulesets/required checks → record workflow identifiers/URLs → OIDC only after target environment authorization → release artifact/SBOM/provenance evidence. GitHub Issues/PRs are execution surfaces; Tunner repository governance remains work-state authority.
