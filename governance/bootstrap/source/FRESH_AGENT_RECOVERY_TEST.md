# Fresh-Agent Recovery Test

Start a new AI session with repository access and no prior Tunner chat. It must verify authority; identify baseline/amendments; milestone/sprint/work item; applicable FRDs/PDRs/ADRs/flows/contracts; mandatory skills; blockers/TODOs/defects; relevant source/tests/history; excluded context; exact next authorized action; and request governed expansion when insufficient.

Auditor variation: repository_access FULL, but no one-shot repository prompt dump; retrieve/index in partitions and synthesize evidence.

PASS requires zero chat-memory dependency, no fabricated authority, no skipped mandatory skill, recorded included/excluded artifacts, stale-context rejection, and next action matching governance.
