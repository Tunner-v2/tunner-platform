# P0 Definition of Ready

P0 is READY when: baseline 1.6.0 active/locked; amendments discoverable; authority hierarchy explicit; P0 scope/backlog/non-goals defined; repository blueprint defined; bootstrap/self-hosting cutover defined; 20 skills + activation rules specified; governance and project-memory templates exist; context modes/retrieval/freshness/escalation specified; GitHub/Actions recognized as P0-generated resources; no unresolved Product decision blocks P0; bootstrap acceptance/evidence criteria defined.
